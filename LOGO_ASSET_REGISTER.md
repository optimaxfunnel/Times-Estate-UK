**PDF:** not generated. No PDF-generation tool exists in this
environment without adding a heavy dependency (a full headless-browser
print pipeline) for a single format. The SVG masters are print-ready
as-is — any print vendor or design tool (Illustrator, Affinity,
Inkscape) can open an SVG and export a press-ready PDF directly; this
is a standard one-step action for whoever prepares the final print
file (who will also need to convert text to outlines at that point —
see `BRAND_GUIDELINES.md` §2.5).
