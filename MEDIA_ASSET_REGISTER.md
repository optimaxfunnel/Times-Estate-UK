rendered on request using the same system already proven in the seven
rendered items.

**Specified, not rendered:** the remaining platform × content-type
matrix —

- **Content types not yet built:** new instruction, price reduction,
  viewing/open house, sold/let agreed, landlord service, market
  update, verified testimonial, recruitment, announcement.
- **Platforms not yet covered with a dedicated template:** LinkedIn,
  X, YouTube, TikTok, WhatsApp Business, Google Business Profile
  (each needs its own crop/safe-area treatment per
  `BRAND_GUIDELINES.md` §7's dimension table — "adapt per platform,"
  not one stretched graphic).

Every one of these follows the same, already-proven system: claret/
ivory palette, the font-free monogram, Playfair Display headline, Work
Sans supporting text, and the same honest labelling of placeholder
property data. This is recorded as a deliberate scope decision (see
`DECISIONS.md`) given the true size of the full matrix (roughly 70
combinations) — not an oversight, and not something to build
speculatively with placeholder listings before it's actually needed.
